# ASA 23 Portfolio — Thembalihle Ngubane

A responsive Next.js starter for a professional portfolio, using a dark navy background and blue accents.

## Before publishing

Review and personalise these items:
1. Confirm the end date for Quatro Security Services. The CV supplied for this project shows `May 202` with the last digit missing.
2. Add links to your GitHub and LinkedIn profiles.
3. Add your other submitted Coursera certificates, with accurate titles and credential links if available.
4. The three project cards are **concepts only**, not completed projects. Build the projects, replace the descriptions with what you actually made, and add repository/live demo links before presenting them as completed work.
5. Add verified programming languages and development tools as you learn them. The current Skills section lists tools and skills found in your CV.
6. Optionally add a public CV PDF download after removing your ID number, home address, references' personal details, and other information that should not be public.

## Run locally

Requires Node.js 18.17 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

To create a production build:

```bash
npm run build
npm start
```

## Deploy

Push this project to a GitHub repository and import the repository into Vercel, or use another platform that supports Next.js. Add your final live URL to your ASA 23 submission.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Lucide icons
